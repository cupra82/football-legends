FOOTBALL LEGENDS - CORREZIONE FOTO MANCANTI

1. Estrai lo ZIP.
2. In GitHub Desktop: Repository > Show in Explorer.
3. Copia la cartella assets estratta nella radice del repository.
4. Quando Windows chiede, scegli di unire le cartelle e sostituire i file omonimi.
5. In GitHub Desktop: Commit to main e Push origin.
6. Quando Render torna Live, premi CTRL+SHIFT+R.

Non modificare index.html, server.js o i database. Non eseguire Run workflow.
