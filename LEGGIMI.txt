INSTALLAZIONE
1. Estrai lo ZIP.
2. In GitHub Desktop seleziona Repository > Show in Explorer.
3. Copia SOLO index.html nella radice del repository, sovrascrivendo il vecchio.
4. Commit to main -> Push origin.
5. Aspetta che Render mostri Live, poi CTRL+SHIFT+R.

Non occorre modificare server.js, Supabase o GitHub Actions.
Le altre immagini rimangono servite da assets/categories.
